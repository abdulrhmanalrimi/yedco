# نظام بوفيه يدكو

تطبيق ويب تقدمي (PWA) عربي لإدارة الوجبات والطلبات والفواتير والتقارير بالريال اليمني.

## المزايا

- تسجيل الطلبات وتوزيع قيمة الوجبة بالتساوي على الموظفين المشاركين.
- إدارة الوجبات والأسعار والموظفين.
- كشف شهري منظم بصيغة Excel، مع كشف مستقل ومفصل لكل موظف.
- إدخال الخصومات الشهرية وحساب صافي المستحق.
- طباعة كشف الشهر والفواتير.
- التثبيت كتطبيق والعمل دون اتصال بعد أول زيارة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

ثم افتح العنوان الذي يظهره Vite.

## البناء

```bash
pnpm check
pnpm build
pnpm start
```

التطبيق يعمل من التخزين المحلي للمتصفح، ولا يحتاج إلى قاعدة بيانات أو مفاتيح API.
